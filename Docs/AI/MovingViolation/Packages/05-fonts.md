# Redistributable Dialogue System fonts

The owned Dialogue System archive ships four Orbitron OpenType weights under the SIL Open Font License 1.1. Their preserved license includes the copyright and reserved font name.

The three Bitwise files are included together under their shipped freeware license. Distribution is free of charge. Retain the original files and notice, and obtain the creator’s permission before charging for distribution.

All five font binaries imported at their original Unity paths and GUIDs in the isolated Unity 6000.3.6f1 test. Restore the original local .meta sidecars with the owned Dialogue System archive when an existing Unity object references those GUIDs.
