# Instant Destruction - Easy GPU Fracture CC0 media

Publisher’s shipped ThirdPartyNotices names these Kenney media files under CC0.
Unity 6000.3.6f1 logged the original path and GUID for all 10 selected files in an isolated import that completed its Asset Database refresh and exited successfully.

This commit contains 10 media files totaling 838,162 source bytes at their original Unity paths.
The full package uses the Unity Asset Store terms and remains in the licensed local intake workflow.
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) and [Asset Store listing](https://assetstore.unity.com/packages/package/380836)

Original media sidecars are recorded with the local source. The public commit includes original sidecars where the shipped notice covers their directory; otherwise rehydrate the shipped sidecars when restoring the full licensed package.
