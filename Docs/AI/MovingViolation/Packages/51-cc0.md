# Oceanis 2026 Pro URP Water Framework CC0 media

The three shipped flare texture directories each contain a CC0 dedication by hackcraft.de. The selected media are confined to those directories.
Unity 6000.3.6f1 logged the original path and GUID for all 92 selected files in an isolated import that completed its Asset Database refresh and exited successfully.

This commit contains 92 media files totaling 1,314,584 source bytes at their original Unity paths.
The full package uses the Unity Asset Store terms and remains in the licensed local intake workflow.
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) and [Asset Store listing](https://assetstore.unity.com/packages/package/289926)

Original media sidecars are recorded with the local source. The public commit includes original sidecars where the shipped notice covers their directory; otherwise rehydrate the shipped sidecars when restoring the full licensed package.
