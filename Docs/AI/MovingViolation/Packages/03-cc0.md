# JU TPS 3 - Third Person Shooter GameKit + Vehicle Physics CC0 media

Publisher’s shipped Third-Party Notices identify the audio and texture directories under CC0 1.0.
Unity 6000.3.6f1 logged the original path and GUID for all 80 selected files in an isolated import that completed its Asset Database refresh and exited successfully.

This commit contains 80 media files totaling 23,684,823 source bytes at their original Unity paths.
The full package uses the Unity Asset Store terms and remains in the licensed local intake workflow.
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) and [Asset Store listing](https://assetstore.unity.com/packages/package/251334)

Original media sidecars are recorded with the local source. The public commit includes original sidecars where the shipped notice covers their directory; otherwise rehydrate the shipped sidecars when restoring the full licensed package.
