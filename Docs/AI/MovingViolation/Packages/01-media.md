# NWH separately licensed sample models

These are the two original FBX files identified by the vendor's shipped notices. The samples retain the exact archive-relative paths below the public redistribution folder. Unity 6000.3.6f1 imported both models, resolved the original GUIDs and found renderers. The extracted files retain the vendor archive's model bytes.

- Italian Hot Hatch by Daniel Zhabotinsky. [Original model](https://sketchfab.com/3d-models/italian-group-a-89-hot-hatch-low-poly-model-97b15b067111443ebe05840137b49c65)
- Akt Tt Ds 200 repainted by e-restrepo1114. The vendor sample is named DualSportMotorcycle. [Original model](https://skfb.ly/ooYFV)

The original attribution notices accompany the FBX files. The complete vehicle physics package, original Unity metadata and prefabs are restored separately through NWH's owned download. [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) and [package intake](01.md).
