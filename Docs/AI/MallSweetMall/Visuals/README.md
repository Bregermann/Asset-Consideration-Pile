# Mall Sweet Mall visual catalogue

The PNG files in this folder were rendered in the studio's existing isolated Unity 6.4 validation editor using the ACP assets and the selected bundled Sundown URP files. They are studio Unity renders. See [the capture index](capture-index.tsv) for exact source paths, prefab GUIDs, measured render bounds, dependency closures and material prep status.

Native captures use the imported materials. Nimikko's source materials are Built-in. Its captures use temporary URP material copies on scene instances and leave the original source intact. These previews establish source geometry and broad surface fit. Glass transparency, transport behavior, collisions and production lighting require a separate TidyCore pass.

Representative contact points include the narrow and wide Nimikko storefronts, Sundown's shelves, Plush Toys, two arcade families, CRTs, the Vintage Computer Keyboard, Burger Shop equipment, Adorable Foods and Toilet Props Set.
