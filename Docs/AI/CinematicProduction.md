## Selective retrieval

Registry validation resolved Recorder 5.1.8, Cinemachine 3.1.8 and Timeline 1.8.10 together in the isolated Unity 6000.4.10f1 project with URP 17.4.0. All three produced script assemblies. Capture, camera behavior and movie encoding remain untested. Recorder and Cinemachine are available for selective install by ID. Depot installation awaits its declared editor or an explicit depot upgrade.

The installed Cinemachine and Timeline packages carry the Unity Companion License. Recorder's package notice applies the Companion License to source code and the Unity Package Distribution License to the rest of the package. Retrieve all three through the Unity Registry.

1. Start with Timeline for sequencing, Cinemachine for camera motion and Recorder for capture. Install Unity Registry packages through Package Manager by ID so the destination resolves its own dependency graph.
2. Retrieve Asset Store packages through **My Assets** in an entitled account or from the verified local Unity cache. Confirm organization rights and any extension seats before team use. Keep vendor archives and source payloads in authorized local storage. Check bundled samples and music separately before using them in marketing output. [Unity Asset Store terms](https://unity.com/legal/as-terms).
3. In a clean project or branch, import only the chosen package and features. Preserve original paths and `.meta` files. Compare incoming GUIDs against installed assets and reuse matching dependencies. Import optional samples only when needed.
4. For automated gameplay marketing, run a deterministic input sequence or replay in Editor Play Mode. Bind Cinemachine cameras and cue audio through Timeline or gameplay events. Use Recorder presets for landscape trailers and separate portrait social renders. Check camera cuts, framing, overlays, audio sync, output resolution and frame rate in a short sample before running a batch. Keep recordings and generated caches out of Git.
5. For Steam trailers, record representative gameplay and retain clean masters locally for alternate edits. For social clips, reframe the gameplay shot and render a dedicated portrait pass rather than relying on a center crop.
